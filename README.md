Descripción
Este proyecto es una página web estática que aplica los conceptos del Laboratorio #2: metadatos de configuración, 
elementos semánticos de HTML5, tablas de datos, hipervínculos seguros y selectores CSS (de etiqueta, clase e ID). 
Incluye además un formulario de ejemplo donde el nombre ingresado se muestra en mayúsculas mediante CSS, 
y un campo de correo con validación nativa de HTML5.

Estructura del proyecto
Laboratorio N°2 - DWeb/
├── index.html        # Página principal
├── estilos.css        # Hoja de estilos externa
└── Logo/
    └── icono.png       # Ícono (favicon) del sitio
    
Características implementadas
Metadatos del documento: charset, viewport, description, keywords, author.
Estructura semántica: header, nav, main, section, aside, footer.
Tablas HTML: informe de gastos de viaje (con th, scope y headers para accesibilidad) y reporte de ventas (con filas alternadas por clase).
Hipervínculos seguros: enlace externo con target="_blank" y rel="noopener".
Selectores CSS: universal, de etiqueta, de clase, de ID y descendiente.
Formulario interactivo: nombre convertido a mayúsculas con text-transform: uppercase, y correo con validación :valid / :invalid.
Favicon personalizado ubicado en la carpeta Logo.
Cómo visualizarlo

No requiere servidor (WampServer, XAMPP, etc.), ya que es HTML/CSS puro.

Descarga la carpeta completa manteniendo la estructura de archivos indicada arriba.
Haz doble clic en index.html y se abrirá directamente en el navegador.

Tecnologías utilizadas
HTML5
CSS3
JavaScript (solo para el año automático del pie de página y el saludo en vivo del formulario)
